Mot Juste is an iPhone and iPad app for finding, keeping, and practising English words: an offline dictionary of 125,000+ words, Find the Word, three new words a day with widgets, spaced review, quizzes, and 40 punctuation and grammar lessons, with on-device Apple Intelligence. No account, no ads, no tracking.

This repository holds the app's public website, which GitHub Pages serves at [chrismahlke.github.io/motjuste](https://chrismahlke.github.io/motjuste/), and its issue tracker. The app's source code is kept in a private repository.

## Getting help

To report a problem or suggest something, [open an issue](https://github.com/ChrisMahlke/motjuste/issues/new). You'll need a free GitHub account. Every issue is read.

It helps to include:

- Your iPhone or iPad and its iOS version
- The word or screen you were on
- What you expected to see, and what you saw instead

The [support page](https://chrismahlke.github.io/motjuste/support/) answers common questions.
